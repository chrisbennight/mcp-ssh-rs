# Changelog

## 0.1.0

Publication status, the source revision, tested image digest, and compatibility
evidence are recorded in the
[GitHub release](https://github.com/chrisbennight/mcp-ssh-rs/releases/tag/v0.1.0).

Initial public release:

- Standalone MCP over stdio or stateless HTTP with operator-managed HTTPS.
- SSH sessions bound to configured accounts and explicit access classes.
- Binary SFTP transfer and bulk command output by file reference.
- Optional account-based human approval and an advisory evaluation interface.
- Required audit records with independently configured diagnostic and audit sinks.
- Apache License 2.0.
