# Get help

Use [GitHub issues](https://github.com/chrisbennight/mcp-ssh-rs/issues) for usage
questions, reproducible bugs, and feature proposals. Maintainer availability
determines response and fix timing; there is no guaranteed response time.

- **Usage question:** describe your goal, the revision you use, and what you
  tried. Start with the [documentation guide](docs/README.md) and
  [quickstart troubleshooting](docs/quickstart.md#common-failures).
- **Bug:** describe expected and actual behavior, your client and deployment
  mode, and steps to reproduce with a disposable target.
- **Feature proposal:** explain who needs it, the problem, and alternatives you
  considered. Discuss substantial changes before implementing them.
- **Contribution:** follow [Contributing](CONTRIBUTING.md). Documentation,
  reproducible examples, and testing are welcome alongside code.
- **Vulnerability:** use the private route in [Security reports](SECURITY.md).
  Do not post vulnerability details in an issue.

Include configuration names when relevant, but remove credential values,
private hostnames, personal data, and unrelated deployment details. Review any
diagnostic excerpt before sharing it; avoid posting full environment dumps.
